# 결정 — L2 거시는 선별에서 빼고 오버레이만 남긴다

**무엇을**: `docs/03` §4 의 `final(t) = 0.70·cycle + 0.30·tailwind` 선언을 철회한다. 테마 선별은 L1
스코어보드(S2)만으로 한다. 남기는 것: `tailwind < −0.5`(커버리지 ≥ 0.5) 하드 제외 · 모순 감사 ·
국면 4분면/credit_stress 플래그 · L3 프롬프트 컨텍스트와 `docs/04` §4 의 확신도 +0.10 규칙.
`msa run monthly` 의 select 단계가 hard_exclude 만 적용하고 제외한 이름을 적는다.

**왜**: (1) 그 0.30 가중은 코드에 배선된 적이 없어 운용상 영향이 0 이었다. (2) 선언의 근거 문장 자신이
거시를 "예측 정확도가 낮은 외생 조건" 으로 불렀다 — 조건이지 선별 기준이 아니다. (3) 외부 증거(`docs/13`)
는 거시 기반 섹터 로테이션의 표본 외 예측력이 약하고 산업 수준 사이클·자본 사이클 신호가 거시와
독립적으로 작동함을 가리킨다. (4) 드라이버 데이터(FRED)가 없어 26 중 3 만 실측 가능하고 부호 일치율
검정이 451 쌍 중 29 만 돈다 — 실측할 수 없는 선언을 순위에 넣을 수 없다.

**같이 적는 것**: 이 결정은 "거시가 쓸모없다" 가 아니라 자리 재배치다. FRED 데이터가 들어오면
`docs/13` §5 의 사전 등록된 증분 검정(S2 단독 vs S2 + tailwind 의 12M rank-IC 차이, hard_exclude
의 사후 12M 수익률)이 "다시 넣을 이유가 있는가" 를 답한다. 값은 그 결과로 고르지 않는다.

**되돌리는 조건**: 위 검정에서 증분 IC 의 CI 하한 > 0 이면 새 절로 기록하고 사람이 다시 결정한다.
