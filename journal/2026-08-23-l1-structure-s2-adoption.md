# 결정 — L1 집계 구조 S2 채택

**무엇을**: 스코어보드의 순위 점수를 "A~F 6블록 가산(S0)" 에서 "A·B 풀 자격(mean(A_pct,B_pct) ≥ 0.5) 안에서
C·E·F 재정규화 가중합(S2)" 으로 바꾼다. 가중치 표(`docs/02` §7)의 값은 바꾸지 않는다. D 는 어느 점수에도
들어가지 않고 프로필 표시용. 구 복합은 `score_s0` 로 계속 산출(감사용).

**왜**: M3.5 관문에서 S0 의 주 창 12M rank-IC 가 0 과 구분되지 않았다(+0.048 [−0.024, +0.123]). 원인은
A·D 가 C·E 와 반대 부호로 상쇄하는 것이었고, `docs/02` 자신이 A 를 조건으로 서술하면서 §7 에서 가산하던
모순이 있었다. `docs/12` §4 에 후보 S1·S2 와 합격 기준을 **실행 전에** 고정하고 같은 관문으로 쟀다 —
S1 FAIL(후보 집합 희소), S2 PASS(+0.078 [+0.015, +0.145], 6칸 전부 CI > 0).

**같이 적는 한계**: DSR(632 시도, 비중첩 15관측) 0.003 · 12M top8−bottom8 스프레드 +2.9%p [−5.0, +10.9](0 포함;
1/3/6M 은 CI > 0) · `commodity_supply` 에서 0 과 구분되지 않음(+0.095 [−0.037, +0.205]). 합격은 "한 경로에서
어긋나지 않았다" 이지 "맞았다" 가 아니다.

**하지 않은 것**: S1 임계 완화, S2′(D 를 풀에), "C 만" 구조 — 새 사전 등록 대상이며 이 결정에 포함되지 않는다.

**되돌리는 조건**: 다음 관문(새 스토어 캐시, `msa backtest l1`)에서 S2 의 주 창 12M CI 하한이 0 아래로 내려가면
`docs/backtest-l1.md` 에 새 절로 기록하고, 되돌릴지는 다시 사람이 결정한다(값을 고치지 않는다).
