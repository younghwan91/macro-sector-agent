## 1. 판정 시점과 국면

판정 시점을 2013-12-31 로 둔 이유: 석탄주는 2011-04 고점 이후 2년 8개월째 하락 중이었고,
2013년은 천연가스 가격 반등으로 발전용 석탄 소비가 **일시 반등한 해**(+34.4 Mst)였다.
즉 "바닥 같아 보이는" 시점이다. 가격·차트는 사이클 저점과 구분되지 않았고, 대형 4사
(Peabody·Arch·Alpha·Walter) 중 파산한 곳은 아직 없었다 (Patriot 만 2012-07 Ch.11).

## 2. 판정 시점의 L1 상태 (정성)

- `coal` 버킷 EW 지수: 2011-04-01 고점 대비 **−60.3%** (2013-12-31), 고점 후 33개월. 구성원 17종.
- 이후 24개월 최저점 2015-12-15 (판정 시점 대비 −85.1%). 즉 2013-12 의 "−60%" 는 바닥이
  아니라 절반이었다.
- 전방 수익률(EW): 12M −41% · 24M −83% · 36M −55%.

## 4. 하드 게이트와 확신도 — 기계적 적용

```
축1 == 사망 AND 축3 ∈ {경고,사망}  → 해당 없음 (축1 = 경고)
축1 == 사망 OR  축3 == 사망        → 해당: 축3 사망 → cycle_confidence 상한 0.35, 포트 편입 불가
축5 24M 만기/시총 > 0.5            → 종목별 미검증 (L4 생존 필터 대상)

base 0.5
−0.20 축1 경고
+0.00 축2 (8분기+ 미검증 → 가점 보류)
+0.00 축3 (사망 — 가점 없음; 상한 0.35 적용)
+0.10 축4 가격 < 원가, 셧다운 발표 관측
−0.15 축5 심각
+0.00 거시 순풍 (미평가)
= 0.25  → min(0.25, 0.35) = 0.25  → 포트 편입 불가 (최소 0.5 미달)
```

**게이트 결과: `rejected` 는 아니지만 상한 0.35 로 편입 불가 (관찰 목록).**
**역사적 결과와 일치하는가: 예.** 판정 시점 이후 24개월 −83%, Alpha(2015-08)·Arch(2016-01)·Peabody(2016-04)
Ch.11 (Walter 2015-07 포함). 규칙은 이 테마를 막았다.

**어긋남 기록 (임계값은 그대로 둔다).** `04` §5 표는 이 쌍의 갈린 지점을 "석탄 −4%/y" 로 적었는데,
2013-12 시점에서 −4%/y 는 **5년 CAGR** 이지 10년 CAGR(−1.6%)이 아니다. 규칙의 사망 조건은
10년 CAGR < −2% 라서, **2013-12 에는 축 1 이 사망이 아니라 경고**다. 판정이 막힌 것은 축 3(대체)
덕분이다. 2015-12 에 재면 10y −3.3%, 5y −5.4% 로 축 1 도 사망이 되어 자동 기각된다.
즉 이 사례는 "축 1 단독으로는 2년 늦게 잡고, 축 3 이 먼저 잡았다" 는 기록이다.
임계값(−2%)을 이 사례에 맞춰 옮기지 않는다.
