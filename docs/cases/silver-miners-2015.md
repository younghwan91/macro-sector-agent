## 1. 판정 시점과 국면

은 가격은 2011-04-28 사상 최고 종가 $48.70 에서 2015-12 $14 안팎까지 약 −72% (연평균 기준 2011 $35.12
→ 2015 $15.68, −55%). 은광주는 가격보다 더 떨어져 버킷 EW 지수 기준 −82% 였다. 2015-12-31 은
저점(2016-01-19) 직전이며, 판정자는 그것을 알 수 없었다 — 4년 9개월째 하락 중인 차트였다.

## 4. 하드 게이트와 확신도 — 기계적 적용

```
자동 기각 / 상한 조항 → 해당 없음 (축1 사이클, 축3 사이클)

base 0.5
+0.15 축1 사이클
+0.00 축2 (8분기+ 미검증)
+0.15 축3 대체 위협 없음
+0.00 축4 (P90·셧다운 다수 미검증 — 사이클이되 '강한' 은 아님)
+0.00 축5
+0.00 거시 순풍 (미평가)
−0.10 소표본 버킷 (n < 5)
= 0.70  → 포트 편입 가능 (≥ 0.5)
```

**게이트 결과: `passed`.** **역사적 결과와 일치하는가: 예.** 12M +97%, 대표 종목 2017-12 까지 +68%~+202%
(최대 +231%~+544%). `04` §1 의 "+300%" 는 저점(2016-01-19)에서 2016-08 고점까지의 대표 종목 최대 상승에 가깝다 —
버킷 EW 로는 판정 시점 대비 12M +97% 다. 숫자를 부풀리지 않는다.

**주의.** 축 1 의 10년 CAGR 부호를 1차 출처로 확정하지 못했으므로 `verified: false`. 4년 CAGR(+4.9%)과
총 실물수요 사상 최고는 확정이다.

## 7. 미검증·한계

- 산업용 수요 2005 값(10y CAGR)을 1차 출처로 확보하지 못함 → `verified: false`.
- 축 2·4·5 의 정량 요건(8분기, P90, 만기/시총)은 확인하지 못해 가점·감점 모두 보류. 그 결과 0.70 은
  **보수적 하한**이다 — 요건이 충족됐다면 0.80~0.90 까지 갈 수 있었다는 뜻이지, 조정하라는 뜻이 아니다.
- 버킷이 소표본(2~3종)이라 EW 지수의 낙폭은 대표 종목군(7종 −72%~−96%)으로 교차 확인했다.
