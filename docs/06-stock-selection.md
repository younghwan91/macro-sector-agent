# 06 · 종목 선정 (L4)

테마가 확정되면 그 안에서 무엇을 살지를 정한다. **전 과정 결정론** — LLM 없음
(`CLAUDE.md` §4). 에이전트의 thesis 는 입력으로 쓰이되 랭킹은 코드가 한다.

## 1. 왜 3축인가

원자재·사이클 테마의 종목 선정은 일반 팩터 투자와 다른 문제다.
사이클 저점의 이 산업에서는 **대부분의 기업이 적자**고, 밸류 팩터는 분모가 음수라 무의미하고,
퀄리티 팩터는 정확히 반대 방향을 가리킨다 (**우량주가 가장 덜 오른다**).

실제로 작동하는 축은 셋이다:

| 축 | 묻는 것 | 실패 시 결과 |
|---|---|---|
| **생존 S** | 논지가 맞을 때까지 살아남는가 | 논지가 맞아도 0 원. 사이클 저점 투자의 1차 사망 원인 |
| **토크 T** | 맞으면 얼마나 크게 움직이는가 | 맞아도 시장 수익. 이 전략을 할 이유가 없어짐 |
| **타이밍 M** | 지금 들어가도 되는 상태인가 | 6개월 더 하락 후 물타기 여력 소진 |

**S 와 T 는 구조적으로 상충한다.** 저비용 대형 생산자는 안 죽지만 3배 안 간다.
고비용 레버리지 생산자는 5배 가지만 그 전에 파산할 수 있다.
그래서 하나로 합산하지 않고 **바벨로 구성한다** (§5).

## 2. 생존 축 (S)

`fin-checkup` 의 `metrics/redflags.py` 를 이식한다.

| 지표 | 계산 | 임계 |
|---|---|---|
| `cash_runway_q` | 현금 / max(0, −분기 FCF) | **< 4분기 = 하드 제외.** 논지 horizon 안에 죽는다 |
| `net_debt_ebitda` | 순부채 / TTM EBITDA (EBITDA≤0 이면 순부채/시총으로 대체) | > 4× 감점, > 6× 하드 제외 |
| `maturity_wall_24m` | 24개월 내 만기 부채 / 시총 | > 0.5 하드 제외 (`04-value-trap.md` 축 5) |
| `interest_coverage` | EBIT / 이자비용 | < 1 감점 |
| `dilution_3y` | 주식수 3년 CAGR | > 15%/y 감점. **테마 레벨에선 저점 신호, 종목 레벨에선 주주가치 파괴** |
| `going_concern` | 감사의견 계속기업 의문 | 하드 제외 (에이전트 또는 SEC 파싱) |
| `liquidity` | 20일 평균 달러 거래대금 | < $2M 감점 (자금 규모 작아 완화 가능, 값은 설정) |
| `price_floor` | 종가 | < $2 감점 (상장폐지·역분할 리스크) |

> **하드 제외는 스코어가 아니다.** 아무리 토크가 커도 4분기 안에 현금이 마르는 기업은
> 후보에서 사라진다. AG·SBSW·MP·ALM 형 트레이드에서 이 필터 하나가 최대 손실을 좌우한다.

## 3. 토크 축 (T)

논지가 맞을 때 이익이 얼마나 폭발하는가. 사이클 투자에서 **초과수익의 원천 전부**다.

| 지표 | 계산 | 읽는 법 |
|---|---|---|
| `margin_headroom` | (섹터 자기이력 P75 마진 − 현재 마진) | 마진 회복 여지 |
| `opleverage` | ΔEBITDA% / Δ매출% (12분기 회귀 기울기) | 고정비 비중의 실측 대용 |
| `fixed_cost_ratio` | (매출 − 변동비 추정) / 매출 | 회계 분해 근사 |
| `price_beta_hist` | 직전 상승 국면에서 EBITDA 의 상품가 탄력성 | **가장 직접적. 다만 표본 1~2 사이클** |
| `equity_leverage` | (순부채 + 시총) / 시총 = EV/시총 | 부채가 주식 수익을 증폭. **S 축과 정면 상충** |
| `marginal_producer` | 마진이 섹터 하위 25% | 원가곡선 상단 = 최대 토크 (`04` 축 4) |

**충돌 처리**: `equity_leverage` 와 `marginal_producer` 는 S 축의 감점 항목과 같은 사실을 본다.
합산하지 않고 **두 축의 값을 둘 다 보존해 바벨 배치에 쓴다.**

## 4. 타이밍 축 (M)

`momentum` 저장소 이식. 개별 종목 레벨은 원본 그대로 쓸 수 있다.

| 지표 | 정의 |
|---|---|
| `stage2` | Minervini: `close > SMA150 > SMA200`, `SMA200` 상승 1개월+, 52주 저점 대비 +30%, 고점 대비 −25% 이내 |
| `rs_rating` | IBD 방식 백분위 (vs 전체 유니버스) |
| `vcp_base` | VCP 수축 패턴 존재 + 거래량 dry-up |
| `from_52w_low` | 저점 대비 상승률 |
| `above_50d` | 50일선 위 여부 |
| `rvol_expansion` | 최근 거래량 확장 |

> **타이밍 축은 가중치가 낮다** (§6). 이유: 물타기가 가능하고 MDD 30% 를 감내하므로
> 진입 정밀도의 가치가 낮다. Stage 2 를 **요구하면** 테마 진입이 항상 늦어진다 —
> 우리는 잊혀진 테마에 **먼저** 들어가려는 것이지 확인된 추세를 따라가려는 게 아니다.
> M 은 순위 조정과 **사다리 1단의 시점 힌트**로만 쓴다.

## 5. 바벨 구성

테마당 2~4 종목, 두 그룹으로:

| 그룹 | 선정 기준 | 역할 | 테마 내 비중 |
|---|---|---|---|
| **앵커 (survivor)** | S 상위 · 저비용 생산자 · 대형 | 논지가 늦게 맞아도 안 죽는다. 물타기 여력의 근거 | 55~70% |
| **토크 (torque)** | T 상위 · S 하드필터 통과 | 논지가 맞을 때의 수익 대부분 | 30~45% |

옵션 그룹 — 테마에 존재할 때만:
- **로열티/스트리밍** (금은: FNV·WPM·RGLD 형) — 원가 리스크 없이 가격 노출. 앵커 대체 가능
- **미드스트림/인프라** (에너지) — 물량 노출, 가격 노출 낮음. 앵커 성격
- **ETF** — 구성종목 수가 `min_constituents` 미만이거나 개별 리스크가 과도할 때 대체

> **2026년 원자재 트레이드의 사후 진단**: AG·SBSW·MP·ALM 은 **4개 전부 토크 그룹**이었다.
> 결과는 좋았지만, 앵커 0개는 설계가 아니라 우연이었을 가능성이 높다.
> 리포트는 매 구성마다 **앵커/토크 비율을 명시**해 이 선택이 의도적이도록 만든다.
> (앵커 0% 를 금지하지는 않는다 — 확신도가 높으면 합리적 선택이다. 다만 **보이게** 한다.)

## 6. 종합 점수와 랭킹

```
rank_score = 0.40·S̃ + 0.40·T̃ + 0.20·M̃          (틸데 = 테마 내 횡단면 백분위)
```

- 하드 제외 필터(§2)를 먼저 적용한 뒤 랭킹
- 앵커 선정: `S̃` 상위에서 `T̃` 가 가장 높은 것
- 토크 선정: `T̃` 상위에서 `S̃` 하위 25% 를 뺀 것
- 가중치 0.40/0.40/0.20 은 **선언**이다 (`CLAUDE.md` §1)

## 7. 리포트에 반드시 표기되는 것

각 후보 종목에 대해:

```
MP · rare_earth · TORQUE
  S 0.42  runway 11q · ND/EBITDA n/a(적자) · 만기벽 0.08 · 희석 3y +9%/y
  T 0.88  마진여지 P75까지 +22pp · opleverage 3.4× · 한계생산자 아니오
  M 0.61  Stage2 아니오 · RS 74 · VCP 베이스 있음 · 52wL +18%
  하드필터: 통과
  주의: 단일 광산 의존 (Mountain Pass), 중국 정책 리스크 (04 축5 warning)
```

**`S` 의 하위 항목을 접지 않는다.** 종합 점수만 보면 4분기 런웨이와 12분기 런웨이가
같은 0.42 로 보인다. 사이클 저점 투자에서 그 차이가 전부다.
