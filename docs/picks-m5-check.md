# M5 사후 대조 — `msa picks` 2026-08-14

`docs/11-roadmap.md` M5 완료 기준의 마지막 항목: **2026-08 시점 `rare_earth`·`silver_miners` 에서
MP·AG 가 토크 축 상위에 오는가.** 추가로 프로토타입 이름 SBSW(`pgm_miners`)·ALM(`rare_earth` —
텅스텐, `lithium` 이 아니다) 도 돌렸고 `lithium` 도 같이 기록한다.

**이 문서는 관측이다.** 결과를 보고 가중치·임계·구성을 고치지 않았다 (`CLAUDE.md` §1). 돌린 뒤
코드에 손댄 것은 셋이고 전부 결과와 무관한 정의 문제다 — ① 현금흐름표가 없는 종목의 런웨이 NaN 을
"통과" 가 아니라 "판정 불가 → 하드 제외" 로 (처음 실행에서 반기 보고 해외발행사 GMTL·IPX·CRML 이 런웨이
없이 S̃ 0.9 로 1위에 올랐다), ② `marginal_producer` 사분위를 관측 4개 미만에서 NA 로, ③ 토크 그룹은
T̃ 가 계산된 종목만. 셋 다 `docs/06` §8 에 근거가 있다. 재현: `uv run msa picks <theme> --asof 2026-08-14`.

명령 실행 조건: 스토어 최종일 2026-08-14 · PIT `datekey ≤ asof` · `price_beta_hist` 는 ETF 벌크
(`SLV`·`PPLT`) 로 계산, `rare_earth` 는 `physical_ref` 미선언, `lithium` 은 manual 파일 없음.

### 읽는 법 — 정직하게

1. **MP·AG 는 각 테마의 토크 축 1위다. 그러나 비교 대상이 1개씩뿐이다.** T 는 6개 구성 요소 중
   3개 이상이 있어야 계산되는데, 두 버킷 모두 매출·EBITDA 이력이 있는 생산자가 2개뿐이다
   (`rare_earth` 의 나머지는 탐사기업·반기 보고 해외발행사, `silver_miners` 는 버킷 자체가 4종목).
   표본 2 의 1위는 "MP 가 토크 상위" 를 **반증하지 않았다** 는 뜻이지 검증이 아니다.
2. **둘 다 앵커로 분류됐다.** 바벨 규칙이 앵커를 먼저 고르고("S̃ 상위에서 T̃ 최고"), MP·AG 가
   S̃ 0.50 으로 상위 절반에 턱걸이하면서 T̃ 최고라 앵커 자리를 가져간다. 그 뒤 토크 자리에 남는
   T̃ 계산 가능 종목이 없어 **토크 0, 앵커 100%** 가 찍힌다. `docs/06` §5 의 사후 진단("4개 전부
   토크 그룹, 앵커 0개") 과 정반대 방향의 치우침이 소표본에서 나온다 — 리포트에 비율이 보이므로
   L5 가 판단할 재료는 있다. 규칙을 바꾸지 않았다.
3. **AG 의 토크 원천은 문서가 기대한 것과 다르다.** 2026-08 은 은 가격 상승 후라 AG 마진이 테마
   자기이력 P75 위에 있다 (`margin_headroom` −22pp). T̃ 를 끌어올린 것은 `price_beta_hist` 1.21
   (SLV 2020-03 → 2026-02 상승 국면에서 매출 대비 EBITDA 개선) 과 `opleverage` 1.0, `fixed_cost_ratio`
   0.50 이다. 즉 2026-08 시점 L4 는 "AG 는 이미 토크를 실현한 생산자" 라고 말한다. 이것은 2025 저점
   시점의 사후 대조가 아니다 — 그 검정은 `--asof 2025-xx` 백테스트 경로의 몫이며 아직 돌리지 않았다.
4. **SBSW 는 이 스토어로는 평가할 수 없다.** SF1 에 행이 0개다 (SQM·BVN 도 같다). 20-F 해외발행사
   커버리지 문제이며 `fund_status=none` 으로 구분해 적는다. 코드가 아니라 데이터 소스의 할 일.
5. **ALM 은 S̃ 1.00 · 종합 1위지만 T 는 없다.** Sharadar 에 분기가 6개(2024-12~)뿐이라 12분기
   회귀·마진 이력이 없다. 런웨이는 3분기 평균 기준 39분기(`runway_basis_q=3`). 이 종목을 고른
   사람의 논지는 토크였을 텐데 데이터는 아직 그것을 잴 수 없다.
6. 하드 필터가 뺀 것 중 눈에 띄는 것: `rare_earth` REA(런웨이 1.9q)·UAMY(2.4q), `pgm_miners`
   TFPM(0.3q)·GROY(0.5q)·VMET(0.2q)·LODE(2.8q)·SIND(2.4q), `lithium` SGML(ND/EBITDA 6.7×)·ATLX(런웨이
   3.97q). TFPM(Triple Flag) 같은 로열티사가 "런웨이 0.3분기" 로 제외되는 것은 FCF 가 배당·인수로
   음수인 탓이지 생존 위험이 아니다 — §8.4 의 로열티 태깅이 없어서 생기는 오제외이며, 그대로 둔다.
