# 02 · 사이클 상태벡터 (L1)

109개 테마 버킷 각각에 대해 **6블록 상태벡터**를 계산한다. 전수·결정론·LLM 없음.
출력은 테마 스코어보드이며, 상위 K개만 L3(에이전트)로 넘어간다.

기호: `P_t` = 테마 지수(동일가중, 총수익), `S_t` = SPY, 모두 일별.
`pct(x, w)` = 값 `x` 의 과거 `w` 기간 내 백분위. `Q_n` = n번째 백분위.

---

## A. 망각 (Forgottenness) — "아무도 안 본다"

우위의 원천은 정보가 아니라 **무관심**이다. 이 블록은 무관심을 계량한다.

| 지표 | 정의 | 근거 |
|---|---|---|
| `dd_10y` | `P_t / max(P_{t-2520..t}) − 1` | 고점 대비 낙폭. 사용자 기준선 −50% |
| `dd_real` | CPI 로 실질화한 낙폭 | **원자재는 필수.** 명목 −40% 가 실질 −60% 인 구간이 있다 |
| `months_since_peak` | 10년 고점 이후 경과 개월 | 낙폭보다 **경과 시간**이 망각의 진짜 척도. 6개월 −50% 는 패닉, 48개월 −50% 는 망각 |
| `liquidity_decay` | `median(DV, 63d) / median(DV, 1260d)` | 거래대금 위축 = 관심 소멸. `DV` = 달러 거래대금 |
| `count_decay` | 버킷 상장 기업 수의 5년 변화 | 파산·합병으로 참여자가 줄었는가 (자본 사이클과 연동) |

**Forgottenness 점수** = `dd_10y`, `months_since_peak`, `liquidity_decay` 의 정규화 평균.
`secular_growth` / `secular_risk` 클래스는 이 블록 가중치를 낮춘다 (§7).

> 함정: `liquidity_decay` 는 시장 전체 거래대금 추세에 오염된다.
> **SPY 대비 상대값**으로 계산한다: `(DV_theme/DV_spy)` 의 비율로.

## B. 베이스 (Basing) — "떨어지기를 멈췄다"

`momentum` 저장소의 VCP 로직을 **지수 레벨로 승격**한 것. 개별 종목의 VCP 는 널리 쓰이지만,
테마 지수의 VCP 는 거의 아무도 안 본다.

| 지표 | 정의 | 임계 근거 |
|---|---|---|
| `vcp_index` | 최근 12개월을 3~4개 하락 수축으로 분해, 각 수축폭이 **단조 감소**하는가 | Minervini 원형. 수축폭이 20% → 12% → 7% 면 매도 압력 소진 |
| `rv_ratio` | `RV(63d) / RV(252d)` | < 0.80 이면 변동성 수축. 도메인 관례값이며 **탐색으로 정하지 않는다** |
| `range_compression` | `(max−min)/mid` (126d) 의 `pct(·, 5y)` | Q20 이하 = 역사적 최저 수준의 레인지 |
| `decline_angle` | log(P) 의 126일 회귀 기울기 − 504일 기울기 | 양수 = 하락 각도 완화. 반등보다 **먼저** 나타난다 |
| `volume_dryup` | `median(DV, 21d) / median(DV, 252d)` | < 0.7 후의 확장이 전형적 베이스 이탈 패턴 |

> `rv_ratio` 와 `range_compression` 은 정보가 겹친다. 둘 다 두는 이유는
> 전자가 일별 변동을, 후자가 추세 폭을 보기 때문 — 급등락하며 제자리인 국면에서 갈린다.

## C. 턴 (Turn) — "돌기 시작했다"

**이 블록에서 브레드스가 이 저장소의 구조적 우위다.**
ETF 만 보는 사람은 지수만 본다. 우리는 Sharadar 로 구성종목 전부를 본다.
브레드스는 지수보다 **먼저** 돈다 — 대형주가 아직 눌려 있어도 절반이 200일선 위면 바닥은 지났다.

| 지표 | 정의 | 읽는 법 |
|---|---|---|
| `mom_13612w` | Keller 13612W (`portfolio-research` `taa/signals.py` 이식) | 부호와 3개월 변화 |
| `above_200` | `P_t > SMA200(P)` | `SMA200` 기울기 부호와 함께 읽는다 |
| `rs_slope` | `(P/S)` 비율의 63일 회귀 기울기 | 양수 = SPY 대비 우위 전환 |
| `rs_trough_bounce` | `(P/S)` 의 현재값 / 252일 최저값 − 1 | 상대 저점에서 얼마나 올라왔는가 |
| **`breadth_200`** | 구성종목 중 `close > SMA200` 비율 | |
| **`breadth_nh6m`** | 구성종목 중 6개월 신고가 갱신 비율 | |
| **`breadth_nhnl`** | (신고가 − 신저가) / 구성원 수, 21일 이동합 | |
| `breadth_lead` | `breadth_200` 이 지수 `above_200` 보다 먼저 돌았는가 | 리드 개월 수 |
| `ew_vs_cw` | 동일가중 지수 / 시총가중 지수 의 63일 변화 | 양수 = 소형주가 앞장, 초기 사이클의 전형 |

> `breadth_lead` 가 이 블록의 핵심 산출물이다. 값이 3~6개월이면
> "지수는 아직 안 보이는데 안에서는 이미 돌았다" — **정확히 우리가 원하는 상태.**

## D. 밸류에이션 (Valuation) — 자기이력 백분위

절대 배수는 산업 간 비교가 무의미하다(광업 P/E 8 vs SaaS P/S 10). **자기 역사와만 비교한다.**

| 지표 | 집계 | 비고 |
|---|---|---|
| `ev_ebitda_med` | 구성종목 **중앙값** | 총합은 대형주가 지배 |
| `ev_sales_med` | 중앙값 | 이익이 음수인 사이클 저점에서 유일하게 작동 |
| `pb_med` | 중앙값 | **원자재에서 P/E 보다 신뢰도 높다** — 장부가 ≈ 자산 대체원가의 하한 |
| `fcf_yield_med` | 중앙값 | |
| `ev_replacement` | (가능한 경우) EV / 순유형자산 | 신규 광산·공장을 짓는 것보다 사는 게 싼가 = 공급 반응의 물리적 조건 |

각각 `pct(·, 10y)` 로 변환. **Valuation 점수** = 저평가 방향 백분위의 평균.

**적자 기업 처리 규칙 (명시 필수)**
- `ev_ebitda`: EBITDA ≤ 0 인 기업은 중앙값 계산에서 **제외하되 제외 비율을 리포트**한다.
  제외 비율 자체가 사이클 위치 신호다 (저점에서 50%+ 가 적자).
- `pb`, `ev_sales`: 전 기업 포함. 사이클 저점에서 유일하게 연속인 지표.
- 규약: **"제외했다" 는 사실이 리포트에 안 보이면 그건 조용한 절단이다** (`CLAUDE.md` §2).

## E. 자본 사이클 (Capital cycle) — **이 저장소의 차별점**

Marathon Asset Management 의 *Capital Returns* 논리. 요지:
**높은 수익률 → 자본 유입 → 공급 과잉 → 수익률 붕괴 → 자본 이탈 → 공급 파괴 → 다음 사이클.**
가격을 예측하지 않고 **공급 측의 관측 가능한 상태**만 본다. 그래서 강건하다.

Sharadar SF1 로 전부 계산 가능하고, **이걸 테마 단위로 집계해 보는 개인은 거의 없다.**

| 지표 | 정의 | 읽는 법 |
|---|---|---|
| `capex_to_da` | Σcapex / Σ(D&A), 12분기 이동평균 | **< 1.0 이 8분기 이상 = 공급 파괴 진행 중.** 이 저장소에서 가장 중요한 단일 숫자 |
| `capex_to_da_years` | < 1.0 이 지속된 분기 수 | 길수록 반응이 격렬하다 |
| `asset_growth` | Σ총자산 YoY | 음수 = 산업이 축소 중 |
| `roic_pct` | 섹터 ROIC 의 `pct(·, 10y)` + 2계도함수 | 저점 + 반등 시작 |
| `share_change` | Σ주식수 3년 변화 | **양수(희석) = 생존 자금조달 국면 = 저점 근처.** 음수(자사주) = 자본 규율 회복 = 중기 |
| `net_debt_ebitda` | 섹터 총합 | 추세가 개선 중인가 |
| `exit_count` | ACTIONS 테이블의 파산·폐지·합병 3년 누적 | 참여자 감소 = 공급 파괴의 직접 증거 |
| `entry_count` | 신규 상장·스핀오프 3년 누적 | **급증 = 사이클 후반 경고** (2021년 SPAC, 2007년 드릴러) |

**Capital cycle 점수** = `capex_to_da` 낮음 + `asset_growth` 음수 + `exit_count` 높음 + `entry_count` 낮음.

> `share_change` 의 해석이 뒤집히는 구간에 주의. 희석은 저점의 증거이자 **주주가치 파괴**다.
> L4 의 생존 축에서 같은 지표가 **감점**으로 쓰인다 (`06-stock-selection.md` §2).
> 테마엔 좋고 종목엔 나쁘다 — 모순이 아니라 두 계층의 역할 차이다.

## F. 펀더멘털 턴 (Fundamental inflection)

| 지표 | 정의 | 읽는 법 |
|---|---|---|
| `rev_yoy_d2` | 섹터 총매출 YoY 의 2계도함수 | **감속의 감속** = 턴. 주가는 여기서 돈다 |
| `ebitda_margin_pct` | 마진의 `pct(·,10y)` | 4분기 방향과 함께 읽는다 |
| `surprise_dir` | 실적 서프라이즈 부호의 4분기 이동평균 | 가능한 경우에만 |
| `guidance_rev` | 컨센서스 리비전 | `portfolio-research` FMP 어댑터가 있으면 |
| `unit_series` | 실물 소비량 시계열. 없으면 **동일 구성원** 매출 / 관련 가격지수 | **실질 물량.** `04-value-trap.md` 축 1 과 공유 |
| `unit_series_median` | 동일 구성원의 **기업당 중앙값** 물량 | 합산이 산업 규모를, 중앙값이 개별 기업 물량을 본다 |
| `unit_cagr_10y` · `unit_cagr_5y` | `unit_series` 의 CAGR | 축 1 판정 임계가 이 값에 걸린다 (`04` 축 1) |
| `unit_cagr_10y_median` | `unit_series_median` 의 10년 CAGR | 합산과 **부호가 갈리면** 산업 축소이지 수요 소멸이 아님 |
| `verdict_post_ss` | 동일 구성원 보정 **후** `unit_series` 에 `04` 축 1 판정표를 적용한 값 | **이것이 축 1 의 판정값이다** |
| `verdict_pre_ss` | 동일 구성원 보정 **전** 산출 — **테마 합산 매출** 기준 `unit_series` 에 같은 판정표를 적용한 값 | 판정용이 아니다. `verdict_post_ss` 와 다르면 `axis1_contested` (`04` §3.1) |
| `sign_split` | `unit_cagr_10y` 와 `unit_cagr_10y_median` 의 부호가 갈리는가 | true 면 `axis1_contested` 의 사유 (`04` §3.1) |
| `ss_n` · `ss_coverage` | 동일 구성원 수와 원 구성원 대비 비율 | **표기 없으면 조용한 절단** (`CLAUDE.md` §2) |
| `ma_flag` | 동일 구성원 표본에 유의미한 인수 이력 기업이 있는가 | true 면 물량에 상향 편향이 남는다 (`04` 축 1 규정 5) |

> `unit_series` 는 여기서 계산하고 가치함정 판별기가 소비한다.
> 매출이 늘어도 물량이 줄고 있으면 가격 효과일 뿐이다.
>
> **정의는 `04-value-trap.md` 축 1 과 하나여야 한다.** 계산이 여기 있고 판정이 저기 있으므로
> 정의가 갈리면 게이트가 다른 숫자로 발동한다. 요지만 옮기면:
> ① 1순위는 **외부 실물 소비량 시계열**(L3 `supply_analyst` 수집)이고
> 매출/가격지수는 그것이 없을 때의 **폴백**이다.
> ② 폴백은 측정 구간의 양 끝에 **모두 존재하는 기업**만으로 합산한다(동일 구성원).
> ③ `ss_n`·`ss_coverage`·`ma_flag` 를 함께 낸다.
> ⑤ **이름은 `04-value-trap.md` 축 1 · `specs/thesis.schema.yaml` 과 하나로 쓴다.**
>   이전 판은 여기서만 `unit_volume_proxy`·`unit_volume_median` 이라 불렀다 —
>   L1 이 만든 것을 하류가 다른 이름으로 받으면 구현에서 두 지표가 된다.
> ④ **구성원이 몇 개 줄었는지는 이 지표가 세지 않는다** — 그건 §E 의 `exit_count` 몫이다.
> 두 블록이 같은 관측을 두 번 세면 04 의 축 1 과 축 2 가 같은 사실을 반대로 해석하게 된다.
> ⑥ **보정 전 산출(`verdict_pre_ss`)은 판정용이 아니라 오직 contested 검출용으로만 쓴다.**
>   게이트·확신도·리포트의 축 1 판정은 전부 `verdict_post_ss` 를 쓴다. 이 한 줄이 없으면
>   합산 기준 판정이 슬그머니 살아나 **공급 파괴가 심할수록 자동 기각되는** 원래 결함으로
>   돌아간다 — 축 1 과 축 2 가 같은 관측을 반대로 해석하던 그 자리다 (`04` 축 1 규정 1·4).

## 7. 집계 — `cycle_class` 별 블록 가중치

각 블록을 0~1 로 정규화(`pct` 기반, 버킷 간 횡단면)한 뒤 가중합.

> **이 표의 값은 선언이다.** 데이터에 맞춰 조정하지 않는다 (`CLAUDE.md` §1).
> 조정하려면 도메인 근거를 이 문서에 추가하고 커밋에 남긴다.

| cycle_class | A 망각 | B 베이스 | C 턴 | D 밸류 | E 자본사이클 | F 펀더 |
|---|---|---|---|---|---|---|
| `commodity_supply` | 0.15 | 0.15 | 0.20 | 0.10 | **0.30** | 0.10 |
| `inventory` | 0.10 | 0.15 | 0.25 | 0.10 | 0.15 | **0.25** |
| `credit_rate` | 0.15 | 0.15 | 0.25 | **0.25** | 0.05 | 0.15 |
| `capex_program` | 0.05 | 0.10 | 0.25 | 0.10 | 0.15 | **0.35** |
| `policy_program` | 0.15 | 0.20 | **0.30** | 0.10 | 0.10 | 0.15 |
| `discretionary_demand` | 0.15 | 0.15 | 0.25 | 0.20 | 0.05 | 0.20 |
| `secular_growth` | **0.05** | 0.15 | 0.25 | 0.30 | 0.05 | 0.20 |
| `secular_risk` | **0.05** | 0.15 | 0.25 | 0.15 | 0.20 | 0.20 |

가중치 근거:
- `commodity_supply` 의 자본 사이클 0.30 — 공급이 이 클래스의 유일한 인과 엔진이다.
- `capex_program` 의 망각 0.05 — 방산·전력망은 애초에 잊혀지지 않는다. 낙폭이 신호가 아니다.
- `secular_*` 의 망각 0.05 — **낙폭에 점수를 주면 사양 산업이 스코어보드 상단을 점령한다.**
  이 한 줄이 가치함정 방어의 1차선이다. 2차선은 `04-value-trap.md` 의 하드 게이트.

## 8. 출력 형식

```
테마 스코어보드 · 2026-08-22 · 109 buckets

rank  theme              class              score   A     B     C     D     E     F    flags
  1   uranium            commodity_supply   0.81   .72   .88   .65   .55   .94   .71   [breadth_lead=4m]
  2   pgm_miners         commodity_supply   0.77   .91   .74   .58   .82   .81   .43   [n=6 소표본]
  3   shipping_drybulk   commodity_supply   0.74   ...
 ...
 61   coal               secular_risk       0.48   ...                                [SECULAR — 게이트 필요]
```

각 테마는 6블록 레이더 차트와 함께 저장된다. **스코어 1개만 보고 판단하지 않는다** —
블록 프로필의 모양이 사이클 위치를 말한다:
- A↑ B↑ C↓ = 아직 바닥 (관심 목록, 진입 이르다)
- A↑ B↑ C↑ E↑ = **진입 구간** ← 목표 상태
- A↓ C↑ F↑ E↓ = 이미 진행됨 (늦음, `entry_count` 확인)
