# 04 · 가치함정 판별기 — 사이클 저점 vs 구조적 사망

> **이 저장소의 핵심 IP.** 나머지 계층은 공개된 기법의 조합이지만, 이 판별기가
> 없으면 전체 파이프라인이 자본 파괴 기계가 된다.

## 1. 문제

L1 스코어보드 상단에 오르는 조건 — 고점 대비 −60%, 4년째 하락, 거래 위축,
밸류 백분위 하위 10% — 을 **완벽하게** 만족한 역사적 사례들:

| 사례 | 시점 | 이후 |
|---|---|---|
| 은광 | 2015-2016 | **+300%** (사이클) |
| 우라늄 | 2020-2023 | **+250%** (사이클) |
| 탱커 | 2021-2022 | **+400%** (사이클) |
| 셰일 E&P | 2020-2022 | **+300%** (사이클) |
| 희토류·리튬 | 2025-2026 | **+30% (본인 실현)** |
| 석탄(연료탄) | 2012-2016 | **−90%, 대형 4사 중 3사 파산** (사망)† |
| 오프쇼어 드릴링 | 2015-2020 | **−95%, 전원 챕터11** (사망) |
| 몰·백화점 REIT | 2016-2020 | **−80%, 회복 없음** (사망) |
| 유선통신·케이블 | 2018-2026 | 배당 함정, 자본 잠식 (사망) |
| 육상 시추 | 2019 | −85% (사망) |
| 중국 사교육 | 2021 | −95% 단일 규제로 소멸 (사망) |

**차트만으로는 두 그룹이 구분되지 않는다.** 밸류에이션으로도 안 된다 —
사망 그룹이 오히려 더 싸다. 두 그룹을 가르는 것은 **공급이 파괴될 때 수요가 남아 있는가** 다.

† 석탄은 2021-2022 에 제철용을 중심으로 급반등했다. 이 사실이 판별을 더 어렵게 만든다 —
**사양 산업도 공급이 충분히 파괴되면 반등한다.** 다만 그 반등은 (a) 늦고 (b) 짧고
(c) 진입 시점을 5년 틀리면 그 전에 파산한다. 이 판별기의 목표는 반등 가능성 자체가 아니라
**진입 가능한 반등** 인지를 가리는 것이다.

## 2. 5개 판별축

### 축 1 · 물량 추세 (Unit demand trend) — **가장 결정적**

가격이 아니라 **수량**을 본다. 가격은 사이클로 −70% 가지만, 수량이 구조적으로 줄면 그건 사망이다.

```
unit_proxy(t) = Σrevenue(t) / price_index(t)
unit_cagr_10y = CAGR(unit_proxy, 10y)
unit_cagr_5y  = CAGR(unit_proxy, 5y)
```

| 판정 | 조건 |
|---|---|
| **사이클** | `unit_cagr_10y ≥ 0` 이고 `unit_cagr_5y` 가 사이클 진폭 안에서 변동 |
| **경고** | `unit_cagr_10y ∈ [−2%, 0)` — 정체. 사이클로도 사망으로도 갈 수 있음 |
| **사망** | `unit_cagr_10y < −2%` 이고 `unit_cagr_5y < unit_cagr_10y` — **감소가 가속 중** |

`price_index` 가 없는 테마(서비스업 등)는 이 축을 쓸 수 없다 → 축 3 에 가중치를 이전하고
그 사실을 리포트에 표시한다. **적용 불가를 통과로 취급하지 않는다.**

> 실측 예시로 읽는 법: 석탄 2014년 — 미국 발전용 석탄 소비량이 2007년 대비 이미 −25%,
> 가스 발전 단가가 석탄 아래로 내려온 뒤였다. 가격이 아니라 **물량이 이미 답을 주고 있었다.**
> 반면 은광 2015년 — 은 수요량은 연 3~5% 성장 중이었고 가격만 −70% 였다.

### 축 2 · 자본 사이클 위치 (Capital cycle)

`02-cycle-state.md` §E 의 지표를 판별 관점에서 재해석한다.

| 관측 | 사이클 해석 | 사망 해석 |
|---|---|---|
| `capex_to_da < 1` 이 8분기+ | 공급 파괴 → 가격 반등 압력 | 좌동 (구분 불가) |
| `exit_count` 높음 | 참여자 감소 → 남은 자의 몫 증가 | 좌동 (구분 불가) |
| `asset_growth < 0` | 축소 후 반등 | 청산 진행형 |

**이 축 단독으로는 판별할 수 없다.** 공급 파괴는 두 경우 모두에서 일어난다.
축 2 는 "반응의 크기" 를 말할 뿐이고, "반응이 오는가" 는 축 1 과 축 3 이 말한다.

> 이것이 자본 사이클 논리의 알려진 한계이며, 이 문서가 존재하는 이유다.
> L1 스코어에서 `capital_cycle` 이 0.30 이나 되므로, **게이트 없이는 사양 산업이 상단을 점령한다.**

### 축 3 · 대체·기술 위협 (Substitution) — **LLM 리서치 영역**

에이전트에게 던지는 질문이 정해져 있다 (`05-agent-research.md` 의 `bear` 역할):

1. 이 제품/서비스의 **최종 수요**를 대체하는 기술이 존재하는가?
2. 대체재의 **상용화 몇 년차** 이고 **침투율**은 얼마이며 **비용 곡선**은 어디인가?
3. 대체가 **비가역**인가? (자본재 교체 주기가 20년이면 되돌아오지 않는다)
4. 규제가 대체를 **강제**하는가? (배출 규제, 수출 통제, 금지 법안)

| 판정 | 조건 |
|---|---|
| **사이클** | 대체 위협 없음, 또는 침투율 < 10% 이고 비용 우위 없음 |
| **경고** | 침투율 10~35%, 비용 교차점 도달 |
| **사망** | 침투율 > 35% 이거나 비용 역전 완료 또는 규제 강제 |

역사 대조: 석탄 vs 가스 — 2012년 미국 가스 발전 단가가 석탄 아래로 내려간 **그 순간**이
비가역 전환점이었다. 오프쇼어 드릴링 vs 셰일 — 2014년 셰일 손익분기가 배럴 $50 아래로
내려오면서 심해 프로젝트($70+)가 자본 배분에서 영구 탈락했다.
**두 경우 모두 주가가 바닥으로 보이던 시점에 이미 판정이 끝나 있었다.**

### 축 4 · 원가곡선과 한계 생산자 (Cost curve)

```
현재 가격 < 산업 원가곡선 90번째 백분위  →  공급이 물리적으로 유지 불가
```

한계 생산자가 현금 원가 아래에서 조업하면 몇 분기 안에 셧다운이 강제된다.
이건 심리가 아니라 **회계적 필연**이다 → 공급 감소 → 가격 반등.

| 판정 | 조건 |
|---|---|
| **강한 사이클** | 가격 < P90 현금원가. 셧다운이 이미 발표되고 있음 |
| **사이클** | 가격 < P75 원가 (감가상각 포함 기준) |
| **무관** | 가격이 원가곡선 상단에 여유 있음 — 저평가는 원가 문제가 아님 |

데이터: Sharadar 에 원가곡선은 없다. **프록시**로 구성종목별
`EBITDA margin` 분포의 하위 25% 가 음수인지, `EBIT` 음수 기업 비율, 셧다운 공시(에이전트).

> 이 축은 사망 산업에서도 작동한다 — 석탄 가격도 원가 아래로 가면 반등했다.
> 그래서 축 4 는 **"반등한다"** 만 말하고 **"진입 가능하다"** 는 말하지 않는다.
> 축 1·3 이 사망 판정이면 축 4 의 반등은 트레이딩용이지 이 저장소의 대상이 아니다.

### 축 5 · 터미널 밸류 리스크 (Terminal value)

논지가 맞아도 **그때까지 살아남는가.**

| 지표 | 위험 신호 |
|---|---|
| 부채 만기 구조 | 24개월 내 만기 도래 부채 / 시총 > 0.5 |
| 자산 재활용성 | 자산이 다른 용도로 전용 가능한가 (오피스 빌딩 vs 광산 vs 유정) |
| 규제 소멸 리스크 | 단일 규제로 사업이 소멸 가능한가 (중국 사교육형) |
| 유지보수 capex | 물량 유지에 필요한 최소 capex 를 감당 중인가 |
| 지리적 집중 | 단일 국가 리스크 (SBSW 의 남아공, 희토류의 중국) |

## 3. 판정 규칙 — 하드 게이트

> **"공격적으로 필터링한다" 는 요구가 코드가 되는 지점.**

```
IF  축1 == 사망  AND  축3 ∈ {경고, 사망}:
        → 자동 기각. L1 스코어 무관. 리포트에 기각 사유 기재.

IF  축1 == 사망  OR  축3 == 사망:
        → cycle_confidence 상한 0.35. 포트 편입 불가 (§07 최소 확신도 0.5).
          관찰 목록으로만.

IF  축5 에서 24M 만기부채/시총 > 0.5:
        → 테마는 유지하되 L4 종목 선정에서 해당 종목 제외 (생존 필터).

ELSE:
        cycle_confidence = f(축1, 축2, 축3, 축4, 축5, 거시 순풍)
```

`cycle_class == secular_risk` 인 6개 버킷은 **게이트를 기본 적용**한다 —
통과를 입증해야 후보가 된다 (`01-theme-universe.md` §3).

## 4. `cycle_confidence` 산출

`referee` 에이전트가 5축 판정과 증거를 받아 산출한다. 규칙:

```
base = 0.5
+0.15  축1 사이클 (물량 성장 중)
+0.10  축2 capex/D&A < 1 이 8분기+
+0.15  축3 대체 위협 없음
+0.10  축4 가격 < P90 원가, 셧다운 발표 관측
+0.10  거시 순풍 tailwind > 0.3
−0.20  축1 경고
−0.15  축3 경고
−0.15  축5 심각
−0.10  소표본 버킷 (n < 5) 또는 자기이력 < 7년
```

값역 [0, 1] 로 클립. **이 계수 역시 선언이며 탐색하지 않는다** (`CLAUDE.md` §1).
`referee` 는 이 규칙을 기계적으로 적용하고, 규칙 밖의 조정이 필요하면
**조정 대신 별도 서술로 남긴다** (`key_uncertainties`).

`cycle_confidence` 는 L5 에서 기대수익 가중치로 직접 쓰인다 (`07-portfolio.md` §2).
그리고 `10-validation.md` 의 캘리브레이션 대상이다 — 0.7 이라 말한 논지들이
실제로 70% 맞았는지가, 이 저장소에서 검증 가능한 유일한 숫자다.

## 5. 케이스 스터디 라이브러리

§1 표의 11개 사례 각각에 대해 **판정 시점의 5축 값을 사후 기입**한 문서를 만든다
(`docs/cases/<case-id>.md`). 목적:

- 판별기의 임계값이 실제 사례에서 올바른 판정을 내는지 **감각 보정**
- 새 사례가 나올 때 대조할 기준선
- 에이전트 프롬프트에 few-shot 으로 제공

> **이것은 백테스트가 아니다.** 성과를 측정하지 않고, 임계값을 이 사례들에 맞춰
> 조정하지 않는다 (그 순간 11개 표본에 대한 오버피팅이 된다).
> 케이스가 판정과 어긋나면 **어긋났다는 사실을 문서에 남기고 임계값은 그대로 둔다.**
> 어긋남이 반복되고 그 이유를 서술할 수 있게 되었을 때만 판별 규칙을 바꾼다.

우선 작성할 6건 (사이클 3 · 사망 3, 대조가 가장 선명한 쌍):

| 쌍 | 사이클 | 사망 | 갈린 지점 |
|---|---|---|---|
| 광업 | 은광 2015 | 석탄 2013 | 축 1 물량 (은 +3%/y vs 석탄 −4%/y) |
| 에너지 | 셰일 E&P 2020 | 오프쇼어 드릴링 2016 | 축 3 비용 역전 (셰일이 심해를 대체 완료) |
| 부동산·인프라 | 탱커 2021 | 몰 REIT 2018 | 축 1 물량 + 축 5 자산 재활용성 |
