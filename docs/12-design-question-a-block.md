## 1. 무엇이 관측됐는가

M3.5 (`docs/backtest-l1.md`) 에서 A(망각) 블록 점수의 횡단면 rank-IC 는 **모든 창·모든 호라이즌에서
음수**이고 CI 상한이 0 아래다.

| 창 | 3M | 6M | 12M |
|---|---|---|---|
| 주 창 (2011–) | −0.108 [−0.143, −0.060] | −0.135 [−0.183, −0.065] | −0.125 [−0.194, −0.031] |
| 전 구간 (1998–) | −0.076 [−0.112, −0.038] | −0.094 [−0.141, −0.040] | −0.079 [−0.139, −0.007] |

지표 단위로는 (주 창, 3/6/12M) `dd_10y` −0.12/−0.15/−0.14 (CI 전부 0 아래), `months_since_peak`
−0.09/−0.11/−0.10 (CI 전부 0 아래), `liquidity_decay` −0.04/−0.05/−0.05 (CI 가 0 에 걸침) — 전 구간도 같은
부호다 (`state/backtests/l1/2026-08-14/ic_indicator.csv`, 재현 `uv run msa backtest l1`). 클래스별로도 A 가
양수인 클래스는 없다 (`commodity_supply` +0.01 이 최대, `capex_program`·`secular_growth` 는 −0.12 로 CI 가
0 아래). 즉 **"더 깊이, 더 오래 잊힌" 테마는 이후 3~12개월에도 계속 뒤진다.**

반면 C(턴)는 모든 창·호라이즌에서 +0.10~+0.13 으로 CI 하한이 0 위다. 복합 `score` 가 0 과 구분되지
않는 산수는 단순하다 — **C·E 가 버는 것을 A·D 가 깎는다** (`backtest-l1.md` §2 끝).

현재 스캔(2026-08-14)에서 횡단면을 그대로 보면 같은 것이 보인다:

| 관측 | 값 |
|---|---|
| `corr(A_pct, C_pct)` (134 테마) | **−0.45** |
| `corr(A_pct, score)` · `corr(C_pct, score)` | +0.33 · +0.41 |
| 프로필 "아직 바닥 (A↑B↑C↓)" 테마 수 · 평균 순위 | 16 · 51위 |
| 프로필 "진입 구간 (A↑B↑C↑E↑)" 테마 수 · 평균 순위 | 3 · 13위 |
| 프로필 "이미 진행 (A↓C↑F↑E↓)" · 평균 순위 | 6 · 79위 |
| 그 외 "혼합" · 평균 순위 | 109 · 71위 |

(프로필 분류 임계는 백분위 ≥0.6 / ≤0.4 — 서술용이며 어디에도 쓰이지 않는다.)

A 와 C 는 **구조적으로 반대**다 — 고점 대비 깊이 오래 떨어져 있다는 것(A↑)과 SMA200 위로 돌아섰다는
것(C↑)은 같은 테마에서 같은 달에 동시에 높기 어렵다. 선형 가중합은 이 둘을 **더한다.** 그 결과 "아직
바닥"(A↑B↑C↓)도, "이미 진행"(A↓C↑)도 아닌 **혼합 프로필이 중간 점수로 상단을 채운다.** 문서가 목표
상태로 적은 "진입 구간"은 3개뿐이고, 그 3개는 상단에 있다 — 즉 원하는 것이 있을 때는 점수가 그것을
찾지만, 대개는 없고 그때 상단은 혼합이다.

## 2. 선언을 다시 읽는다 — 문서 자신이 두 가지로 말하고 있다

`docs/02-cycle-state.md` 는 A 를 두 곳에서 서로 다르게 다룬다.

| 자리 | 서술 | A 의 역할 |
|---|---|---|
| §A 머리 | "우위의 원천은 정보가 아니라 **무관심**이다. 이 블록은 무관심을 계량한다" | **어디를 볼지** — 후보 풀의 정의 |
| §8 프로필 | "A↑ B↑ C↓ = 아직 바닥 (관심 목록, **진입 이르다**)" · "A↑ B↑ C↑ E↑ = **진입 구간**" | **필요조건** — A 가 있어야 후보, 진입은 C·E 가 말한다 |
| §7 가중치 표 | A 0.05~0.15 를 B~F 와 **같은 줄에서 가산** | **가산 항** — A 가 클수록 점수가 오른다 |
| `00-overview.md` §1 | "**아무도 보지 않는 테마가** 사이클 저점에서 **돌아설 때** 먼저 들어가 있는 것" | 관계절(아무도 보지 않는) + 주절(돌아설 때) — **조건 + 타이밍** |

§A·§8·`00` 은 A 를 **조건**으로 서술하고, §7 만 A 를 **점수**로 집계한다. M3.5 는 그 §7 을 검정했고,
조건을 점수로 더하면 예측력이 음수라고 답했다. 이것은 A 의 정의가 틀렸다는 뜻이 아니다 — "아직 돌지
않은 것" 이 다음 12개월에도 뒤진다는 것은 **A 의 정의상 당연**하다 (3~12개월 호라이즌에서 낙폭은
지속되고, 장기 반전은 3~5년 호라이즌의 현상이다). 틀린 것은 **조건을 가산 항으로 쓴 집계 방식**일
가능성이 크다. 이것이 이 문서가 적어 두는 설계 질문이다:

> **A(망각)는 "점수에 더하는 것"이 아니라 "후보 집합을 정하는 것"이어야 하는가?**

같은 질문이 D(밸류)에도 걸린다 (§5).

## 3. 설계 공간 — 선택지와 각각의 비용

아래는 **열거**다. 이 문서는 고르지 않는다 (§4 의 절차가 고른다).

| # | 구조 | 서술 | 장점 | 위험·비용 | 규약과의 관계 |
|---|---|---|---|---|---|
| (a) | **현상 유지** — 선형 가산 | §7 그대로. A 0.05~0.15 | 아무것도 바꾸지 않는다. 판정은 이미 기록됐다 | M3.5 FAIL 이 서 있다 → 복합 `score` 는 순위 근거로 쓸 수 없다(`README`). M5·M6 의 입력이 사실상 없다 | 가장 보수적. 그러나 "틀린 선언을 고치지 않는 것" 도 선택이다 |
| (b) | **A(·B) 를 게이트로** — 후보 집합 = A 조건 충족 테마, 순위는 C·E·F(·B) 로 | §8 의 "A↑ B↑ 가 있어야 후보" 를 그대로 코드로. A 의 가중치는 0, 대신 **자격 조건** | 문서의 원래 서술과 정합. 조건이 **절대 기준**(아래)이면 탐색 여지가 없다 | 게이트 기준을 어디에 둘지가 새 선언. 후보 집합이 비는 달(전 시장 강세기)이 생긴다 — 그것은 결함이 아니라 "살 것이 없다" 는 답이지만, M5·M6 이 빈 입력을 다룰 수 있어야 한다 | 임계값의 **신설**이다. 도메인 근거가 있으면 허용(`CLAUDE.md` §1 "도메인 근거에서 오거나, 없으면 그렇다고 적는다") |
| (c) | **2단 점수** — 풀 점수(A·B)와 타이밍 점수(C·E·F)를 **별도 축**으로, 최종 순위는 타이밍 점수·풀 점수는 자격 | (b) 의 연속형. 리포트에 두 축을 나란히 | 프로필 읽기(§8)를 기계가 한다. "아직 바닥" 과 "진입 구간" 이 같은 점수로 섞이지 않는다 | 자격 컷(풀 점수 ≥ q)이 새 선언. 두 점수를 어떻게 결합할지가 또 한 번의 선택 | (b) 와 같음 |
| (d) | **상호작용** — A×C 항 | A 가 높을 때만 C 에 점수 | 수학적으로 (b)(c) 를 한 식에 담는다 | 비선형. 해석이 어렵고 "계수를 조금" 의 유혹이 가장 크다 | 탐색 유혹이 가장 큰 구조 — 이 저장소의 지배적 실패 유형(§1)과 정면 충돌 |
| (e) | **A 를 음의 항으로** (부호 반전) 또는 A·D 가중치 0 | 데이터가 말하는 방향으로 값을 옮긴다 | IC 가 오른다 | 정확히 `CLAUDE.md` §1 이 금지하는 일이다. 608 시도 중 최선을 고르는 행위 | **금지** |

문서의 원래 서술(§A·§8·`00`)과 가장 정합적인 것은 (b)/(c) 다. 그러나 (b)/(c) 도 **데이터를 본 뒤의
구조 변경**이다. `CLAUDE.md` §1 이 금지하는 것은 "값을 데이터에 맞춰 옮기는 것" 이고, 구조 변경은
그 문장에 직접 걸리지 않지만 **같은 위험**(단일 경로 오버피팅)을 같은 크기로 갖는다. 그래서 이 문서는
(b)/(c) 를 고르지 않고, **고르는 절차를 고정**한다.

## 4. 결정 절차 — 사전 등록 (M3.6 제안)

**원칙: 후보 구조와 합격 기준을 데이터를 더 보기 전에 적는다. 적은 뒤에 돌린다. 돌린 뒤에 값을 고치지 않는다.**

### 4.1 후보 구조 (정확히 둘, 여기서 고정)

| 후보 | 정의 |
|---|---|
| **S0 현행** | `score = Σ_b w_class[b] · pct(block_b)`, A 포함 (`scoreboard.py` 그대로) |
| **S1 절대 게이트** | 후보 집합 `G(t) = { i : dd_10y_i(t) ≤ −0.50 AND months_since_peak_i(t) ≥ 12 }`. 순위 점수 = `Σ_{b∈{B,C,D,E,F}} w_class[b]·pct(block_b)` 를 `w` 재정규화(A 의 가중치를 나머지에 비례 배분). G 밖의 테마는 순위 없음(관찰 목록) |
| **S2 풀 점수 자격** | 풀 점수 `P = mean(pct A, pct B)`, 타이밍 점수 `T = Σ_{b∈{C,E,F}} w·pct` 재정규화. 자격 = `P ≥ 0.5` (횡단면 중앙값 이상). 순위 = T, 자격 미달은 관찰 목록 |

S1 의 두 기준은 탐색이 아니라 **문서에 이미 있는 값**이다 — −50% 는 `docs/02` §A 의 "사용자 기준선 −50%",
12개월은 §A 의 "6개월 −50% 는 패닉, 48개월 −50% 는 망각" 사이의 하한(패닉이 아니려면 최소 1년)이다.
S2 의 0.5 는 "중앙값 이상" 이라는 무정보 컷이다. **둘 다 여기서 고정하고, 결과를 본 뒤 0.45 나 −0.40 으로
옮기지 않는다.** 옮기고 싶으면 그것은 새 후보(S3)이고 시도 수에 더해진다.

### 4.2 검정 (관문 0 과 같은 규칙)

- 같은 데이터(`state/cache/l1_*`), 같은 창(주 창 2011– · 보조 전 구간), 같은 호라이즌(3·6·12M), 같은
  부트스트랩(12개월 블록, 2000회, 시드 0), 같은 최소 횡단면(20 — S1 은 G(t) 가 20 미만인 달을 **제외하고
  센다**, 제외 수를 보고한다).
- 합격 기준: **주 창 · 12M · 순위 점수의 rank-IC 95% CI 하한 > 0** (관문 0 과 동일). 보조로 top-8 vs
  bottom-8 스프레드(S1·S2 는 G 안에서).
- 시도 수: 기존 608 + 후보 2 × 창 2 × 호라이즌 3 × (IC + 스프레드 2) = **+24 → 632.** DSR 은 632 로 정산한다.
  이 절차 자체가 "결과를 보고 구조를 고른" 시도이므로 S1·S2 의 DSR 에는 그 사실을 함께 적는다.
- 기록 위치: `docs/backtest-l1.md` 에 **새 절로 덧붙인다** (기존 절은 고치지 않는다, §10).

### 4.3 결과별 조치 (미리 고정)

| 결과 | 조치 |
|---|---|
| S1·S2 둘 다 불합격 | 구조도 그대로 둔다. 복합 `score` 의 "관찰 지표" 강등 유지. 이 문서에 결과를 적고 닫는다 |
| 하나 이상 합격 | **자동 채택 아님.** 사람이 읽고, 채택한다면 (i) `docs/02` §7·§8 개정(근거 서술 포함) (ii) `scoreboard.py` 변경 (iii) `README` 강등 문구 갱신 (iv) 저널에 결정 항목 — 을 **하나의 별도 커밋**으로. 합격은 "맞았다" 가 아니라 "한 경로에서 어긋나지 않았다" 다 (`docs/10` §2.3 넷째 행) |
| 둘 다 합격 | 더 단순한 쪽(S1)을 우선 검토한다 — IC 가 높은 쪽이 아니라 |

### 4.4 하지 않는 것

- S1·S2 의 임계를 결과를 보고 옮기는 것. 다른 게이트 변수(`liquidity_decay` 등)를 추가해 보는 것 — 각각이
  새 시도이고, 이 문서는 그 문을 열지 않는다.
- "C 만 쓰는" 구조(S3) 를 후보에 넣는 것 — `backtest-l1.md` §9 가 이미 기각한 이유 그대로다.
- 검정이 통과했다는 이유로 M5·M6 의 입력을 자동으로 바꾸는 것.

## 9. 후속 (2026-08-24) — §4.4 의 "S3 는 만들지 않는다" 를 다시 연 기록

§4.4 는 *"'C 만 쓰는' 구조(S3) 를 후보에 넣는 것"* 을 하지 않는다고 적었고, §7 은 후속 질문이

`docs/17-l1-score-structure-preregistration.md` (M3.7), 결과는 `docs/backtest-l1.md` §14.

문을 연 근거는 데이터가 아니라 **역할 변경**이다: 사용자가 "가장 중요한 건 섹터를 잘 골라주는 것"
이라고 시스템의 역할을 다시 못박았고, L4 선정은 은퇴했다(`journal/2026-08-24-l4-selection-retired.md`).

`docs/17` §1.2 가 정면으로 적었다.**
