# 00 · 개요 — 무엇을 왜 만드는가

## 1. 문제 정의

의사결정자는 **직업이 있는 개인**이다. 이 제약이 설계 전체를 지배한다.

| 제약 | 설계에 미치는 영향 |
|---|---|
| 시간 — 주 수 시간 | 의사결정 주기는 **월 단위**. 일중·일간 신호는 만들지 않는다 |
| 정보 우위 없음 | 애널리스트보다 빠를 수 없다. **아무도 안 보는 곳**에서만 우위가 성립한다 |
| 자금 규모 작음 | 유동성 제약이 거의 없다 → **소형주·마이크로캡 접근이 가능한 것이 유일한 구조적 우위** |
| 손실 감내 MDD 30% | 집중과 변동성을 감당할 수 있다. 분산으로 알파를 희석할 이유가 없다 |
| 물타기 가능 | 진입 타이밍의 정밀도 요구가 낮아진다. 대신 **사다리를 사전에 계획**해야 한다 |
| AI 에이전트 활용 가능 | 도메인 리서치(물리적 수급·정책)를 사람보다 넓게 돌 수 있다 |

이 조건에서 기대값이 가장 높은 전략은 **하향식 테마 사이클 진입**이다.
팩터 알파(`portfolio-research` 가 이미 함)는 소수점 경쟁이고, 데이 트레이딩은 시간 제약에 걸리며,
지수 추종은 초과수익이 정의상 0 이다. 남는 것은 **시간축의 비대칭** —
사이클이 도는 데 6~24개월이 걸리고, 기관은 그 기간을 기다릴 수 없다.

## 2. 이 저장소가 답하는 세 가지 질문

1. **지금 어느 테마가 잊혀졌고, 돌아설 준비가 되었는가?** (L1; L2 는 역풍·모순을 걸러 주는 오버레이 — `docs/03` §4.1)
2. **그것은 사이클 저점인가, 구조적 사망인가?** (L3 + L4의 판별기 → `04-value-trap.md`)
3. **그 안에서 무엇을 · 얼마나 · 어디서 더 사고 · 어디서 자르고 · 어디서 파는가?** (L5 + L6)

세 번째 질문에 답하지 못하는 리서치는 이 저장소에서 미완성이다.
"XLE 가 좋아 보인다" 는 산출물이 아니다.

**LLM 이 파이프라인의 좁은 허리에만 있는 것이 의도다.** 위(L1·L2)는 전수·결정론이라
싸고 재현 가능하고, 아래(L4·L5)도 결정론이라 편향이 안 들어온다.
LLM 은 코드가 못 하는 것(물리적 수급, 정책, 대체 위협)만 한다.

## 4. 왜 "섹터"가 아니라 "테마"인가

2026년 원자재 트레이드의 4종목은 GICS 로는 전부 **Basic Materials 한 칸**이다.

| 티커 | 실제 노출 | GICS 섹터 |
|---|---|---|
| AG | 은 (통화 + 산업 수요) | Basic Materials |
| SBSW | PGM (자동차 촉매 + 남아공 공급 리스크) | Basic Materials |
| MP | 희토류 (미중 수출통제 + 방산 공급망) | Basic Materials |
| ALM | 리튬 (EV 수요 + 공급 과잉 해소) | Basic Materials |

네 개는 드라이버가 **전부 다르다**. 11섹터 해상도로는 이 트레이드가 보이지 않고,
동시에 **넷이 같은 잠재 팩터(달러 약세 + 실물자산 + 공급 부족)에 로딩된다**는 사실도 보이지 않는다.
전자는 L1 의 해상도 문제이고, 후자는 L5 의 집중도 문제다. 둘 다 해결해야 한다.

→ 분석 단위는 **134개 테마 버킷** (`01-theme-universe.md` — M2 실측 확정).

## 5. 비목표 (Non-goals)

명시적으로 **하지 않는 것**들. 범위가 흐려지면 이 저장소는 세 번째 백테스트 엔진이 된다.

- **전략 성과 주장** — L5·L3 가 백테스트 불가라 전략 수익률이라는 물건이 만들어지지 않는다.
  결정론 계층의 **스코어 예측력**은 재고 관문을 붙인다 (`10-validation.md` §2)
- **팩터 알파 재발명** — `portfolio-research` 가 이미 158팩터와 walk-forward 를 갖고 있다
- **자동 주문 집행** — 산출은 매매계획까지. 집행은 사람
- **일중/일간 신호** — 의사결정 주기는 월간, 점검은 주간
- **한국 시장** — `kr-quant`·`quant-airflow` 계열의 영역. 이 저장소는 미국 상장만
- **LLM 종목 추천** — 규약 §4 (`CLAUDE.md`)
- **파라미터 최적화** — 규약 §1

## 6. 기존 저장소와의 경계

| 저장소 | 가져오는 것 | 방식 | 이유 |
|---|---|---|---|
| `portfolio-research` | Sharadar 어댑터 · PIT 스토어 · 13612W/SMA 시그널 | **vendoring (복사)** | 저 저장소의 서브시스템 격리 규약을 깨지 않기 위해. 이 저장소는 PIT 를 부분 완화하므로 요구사항도 갈라진다 |
| `momentum` | Stage 분석 · VCP · RS Rating | vendoring + **지수 레벨로 승격** | 원본은 개별 종목용. 테마 지수에 올리는 것이 이 저장소의 기여 |
| `fin-checkup` | 재무 레드플래그 · 텔레그램 · 스케줄러 | vendoring | L4 생존 축과 L6 배달에 직결 |

**의존성이 아니라 복사인 이유**: 세 저장소는 각자의 규약과 릴리스 주기를 갖는다.
git 의존으로 묶으면 한쪽 리팩터가 다른 쪽을 깨고, `portfolio-research` 의
"서브시스템 간 import 금지" 규약이 우회된다. 복사한 파일은 헤더 주석에
**출처 저장소·커밋 해시·복사 일자**를 남긴다.
